2.2. Показання акселерометра — для підтвердження ударів підвіски та
відсіювання хибних спрацювань.
2.3. Геолокація (GNSS) — для прив'язки дефектів до ділянки дороги.
2.4. Технічні метрики: заряд батареї, температура, частота кадрів, обсяг
вільного місця — для адаптації режиму роботи.

5.2. Геолокація — потрібна для координат дефектів; без неї звіт формується без
