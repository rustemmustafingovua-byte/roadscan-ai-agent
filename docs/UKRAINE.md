# RoadScan AI Agent — український ринок

Документ фіксує все, що відрізняє українську поставку від «просто перекладеного
інтерфейсу»: мову, гроші, термінологію ДСТУ, реквізити, демонстраційну ділянку
та вимоги, які перевіряє замовник.

## 1. Мова

* **Основна мова — українська.** Усі екрани, підказки TTS, PDF-відомість,
  Excel-кошторис, GeoJSON-властивості та титри відео за замовчуванням
  українською (`DocStrings.Uk`, `CoreMessages.DEFAULT = Uk`).
* **Друга мова — російська.** Повний переклад інтерфейсу (`values-ru`) і
  документів (`DocStrings.Ru`). Перемикається системною локаллю або
  `adb shell cmd locale set-app-locales ai.roadscan.app --locales uk-UA`.
* Назви дефектів у звітах — з українською відмінковою формою:
  «Яма», «Сітка тріщин», «Колійність», «Заплатка», «Люк», «Невідомо».
* У документах немає «русизмів» на кшталт «смета», «покрытие», «ведомость
  дефектов»: використовуються «кошторис», «дорожнє покриття», «відомість
  дефектів».

## 2. Гроші

| Параметр | Значення |
|---|---|
| Валюта | гривня, `₴` / `UAH` |
| ПДВ | 20 % (ставка за замовчуванням, налаштовується в `price_catalog.json`) |
| Округлення | суми — до копійок, площі — до 0,1 м², об'єми — до 0,01 м³ |
| Формат у документах | `1 234 567,89 ₴` (пробіл — розділювач тисяч, кома — десяткові) |
| Реквізити замовника | найменування, ЄДРПОУ, адреса, договір |
| Об'єкт | назва ділянки, дорога/вулиця, км + м |

Кошторис будується за формулами `V = S·(H+Δ)/1000` та `M = V·ρ·K_упл`; ціни
беруться з регіонального довідника, який постачальник оновлює разом із
замовником. ПДВ додається окремим рядком: «Разом без ПДВ» → «ПДВ» →
«ВСЬОГО (з ПДВ)».

## 3. Термінологія та норми

Продукт не замінює метрологію, але говорить мовою галузі:

| Що використовує застосунок | Нормативна база |
|---|---|
| Дорожнє покриття, проїзна частина, узбіччя, тротуар | ДБН В.2.3-4:2015 (автомобільні дороги) |
| Гранично допустимі розміри вибоїн, колійності | ДСТУ 3587-97 (вимоги до експлуатаційного стану) |
| Види ремонтів: поточний, середній, капітальний | ГБН Г.1-218-182:2011 |
| Кошторис, накладні, ПДВ | ДСТУ Б Д.1.1-1:2013 (правила визначення вартості) |
| Класифікація дефектів для відомості | внутрішній довідник + узгодження із замовником |

У відомості дефектів кожен кластер має: ID, тип, критичність 1–5, статус
(«підтверджено» / «лише візуально»), площу, максимальну та середню глибину,
координати. Кластери «лише візуально» до кошторису **не включаються** — це
прямо написано в примітці документа, щоб кошторис не «роздувався» тенями та
лужами.

## 4. Демонстраційна ділянка

Для показу та приймання використовується ділянка у Києві:

* **Адреса:** вул. Дилова (Дарницький район), Київ.
* **Що демонструє:** яма з водою та руйнуванням країв, сітка тріщин навколо,
  заплатка поруч; покриття — асфальтобетон.
* **Демо-режим:** `loadDemoReport()` наповнює звіт синтетичними кластерами з
  реальними координатами ділянки, щоб показати PDF/Excel/GeoJSON без виїзду.
* **Демо-відео:** не входить у репозиторій (важке). Для показу береться будь-який
  ролик із галереї телефона — 10-секундний фрагмент ділянки достатньо, щоб
  показати цикл «сире відео → ролик із рамками та титрами».

## 5. Що перевіряє замовник (і що ми показуємо)

1. **Мова документів** — PDF і Excel відкриваються українською, без «кракозябр»
   (шрифти з кирилицею вбудовані).
2. **Гривня та ПДВ** — суми збігаються з ручним розрахунком до копійки.
3. **Площі** — звіряються з рулеткою на 3–5 ямах; допуск ±10–15 % після
   калібрування під конкретний автомобіль.
4. **Відсіювання** — тіні, лужи, розмітка, люки не потрапляють у кошторис;
   мета — ≥85 % відфільтрованих хибних спрацювань (перевіряється польовими
   заїздами, див. `docs/ACCEPTANCE.md`).
5. **Офлайн** — режим польоту, повний цикл «проїзд → звіт → шаринг» без мережі.
6. **Відеозвіт** — ролик з титрами українською, рамками `ID · Впевненість`,
   без звуку; надсилається замовнику одним дотиком.

## 6. Локалізація поза екранами

* **TTS:** підказки Ukrainian TTS (Google TTS `uk-UA`); якщо голос не
  встановлено — текстові підказки HUD залишаються.
* **GeoJSON:** `properties.name`, `properties.status` — українською; ключі
  латиницею (`type`, `area_m2`, `severity`) для сумісності з ГІС.
* **Excel:** назви аркушів «Зведення», «Кошторис», «Відомість», «Метрики»;
  числові формати — з комою як десятковим розділювачем.
* **PDF:** A4, поля 15 мм, шапка з реквізитами, підпис оператора та місце для
  підпису замовника.

## 7. Юридичні межі

* Застосунок — інструмент **передпроєктного обстеження** та планування робіт.
  Офіційні документи для експертизи потребують підпису відповідальної особи, а
  вимірювання — атестованої методики.
* Геодані оператора не покидають пристрій; у звіт потрапляють лише координати
  дефектів і метрики сесії.
* Для публічних закупівель кошторис узгоджується з чинним довідником
  регіону — постачальник не гарантує цін поза переданим довідником.

## 8. Двомовність у коді

| Шар | Українська | Російська |
|---|---|---|
| UI-рядки | `app/src/main/res/values/strings.xml` | `values-ru/strings.xml` |
| Документи | `DocStrings.Uk` | `DocStrings.Ru` |
| Повідомлення агента | `CoreMessages.Uk` (DEFAULT) | `CoreMessages.Ru` |
| Титри відео | `strings.xml` → `VideoTexts` у `VideoViewModel.texts()` | `values-ru/strings.xml` |

Додаючи новий рядок, перекладайте його в обидва файли: набір ключів у
`values` і `values-ru` має збігатися, інакше частина екрана «зникає» в
російській локалі.
