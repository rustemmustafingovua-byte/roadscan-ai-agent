# Сторонние компоненты

## Модель детекции дефектов дорожного покрытия

**Файл в приложении:** `app/src/main/assets/roadscan_yolov8.tflite`
**Источник:** [huggingface.co/Logesshhh/road-anomaly-pothole-yolov8m](https://huggingface.co/Logesshhh/road-anomaly-pothole-yolov8m)
**Лицензия:** Apache License 2.0
**Архитектура:** YOLOv8m, вход 512×512 float32 (NHWC), выход `[1, 11, 5376]`
**Поставка:** dynamic-range int8 (веса int8, вход/выход float32), 26 МБ

Модель обучена на открытых наборах данных дефектов дорожного покрытия
(CRDDC/RDD2022, PotBot и др.) и дообучена авторами репозитория на собственных
данных. В приложении используются классы `Pothole`, `Crack`, `Crack-Severe`;
классы транспорта и лежачих полигонов отбрасываются на этапе постобработки
(`YoloV8Detector.labelToType`).

Apache License 2.0 требует указания авторства при распространении — этот файл
является таким указанием. В приложении тот же текст доступен офлайн:
«Налаштування» → «Правова інформація» → «Сторонні компоненти».

### Почему именно эта модель

Модель RDD2022, которая была в приложении раньше, на реальных украинских
кадрах **не находила крупные ямы вообще**: на контрольном наборе (13 кадров с
ямой) полнота составляла 0 %. Замер выполнен инструментом `tools/eval_models.py`:

| Модель | Полнота на ямах | Ложных на чистом асфальте | Классов |
|---|---|---|---|
| RDD2022 YOLO11n (была в приложении) | 0 % | 0 | 6 |
| **YOLOv8m pothole-crack (текущая)** | **100 %** | **0** | 7 |
| PotBot YOLOv8m (только ямы) | 100 % | 13 из 13 | 1 |
| YOLO11n pothole (CC-BY-4.0) | 85 % | 5 из 13 | 2 |

Замер — на украинском видео с ямой (`roadscan-demo.mp4`, 1280×720): 13 кадров
с дефектом и 13 кадров чистого асфальта. Команда:

```bash
.venv/bin/python tools/eval_models.py --frames <каталог> --models model.pt
```

**Ограничение.** Набор маленький и собран из одного ролика; полноту на
украинских дорогах нужно подтверждать полевыми заездами по
`docs/ACCEPTANCE.md`. Для официальных смет нужна модель, дообученная на
локальном размеченном датасете заказчика — процедура дообучения описана в
`docs/UKRAINE.md`.

### Квантизация

Модель поставляется в dynamic-range int8: веса int8, вход и выход float32,
поэтому приложение не меняется. Потери на контрольном наборе отсутствуют —
13/13 детекций и 0 ложных срабатываний, класс и бокс совпадают с float32
с точностью лучше пикселя.

### Как пересобрать модель

```bash
# 1. ONNX из весов PyTorch
python -c "from ultralytics import YOLO; YOLO('pothole_yolov8.pt').export(format='onnx', imgsz=512, opset=13, simplify=True)"

# 2. ONNX -> TFLite (float32 / float16 / int8)
python -m onnx2tf -i pothole_yolov8_512.onnx -o out -b 1 -osd
python -m onnx2tf -i pothole_yolov8_512.onnx -o out -b 1 -oiqt

# 3. положить в assets и обновить labels.txt (порядок классов!)
```

Обходные пути для сборочного окружения (например, недоступный URL тестовых
данных onnx2tf) описаны в `tools/export_tflite.py`.
